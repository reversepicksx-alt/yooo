# Run and deploy your app

This contains everything you need to run your app locally.

View your app in the workspace: https://ai.studio/apps/a5d3ac90-a003-48f3-8f5c-565a801543a6

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. No external generation key is required. Predictions use the deterministic
   projection ledger and API-Football data.
3. Run the app:
   `npm run dev`

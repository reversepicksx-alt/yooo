---
name: Flat analysis context
description: Tactical analysis context should use compact flat sections instead of nested rounded cards.
---

Primary tactical context such as next-opponent pressure and role/position should read as lightweight analysis evidence, not as large dashboard cards. Prefer a small colored left accent, compact header, text rows, and subtle separators over nested backgrounds, borders, and rounded metric boxes.

**Why:** The analysis screen had too many stacked boxes competing with the prediction and making the evidence feel heavier than the decision.

**How to apply:** Keep the evidence and provenance visible, but preserve visual hierarchy through spacing, type scale, and one accent line. If a new tactical card is added, flatten it by default and only use a bordered container when the content genuinely needs separation.

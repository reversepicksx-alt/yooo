---
name: Player cohort analysis language
description: Analysis pages must distinguish comparable player-event averages from true team-level allowed metrics.
---

When evidence is built from players who recorded a prop against an opponent, describe it as a matchup sample or comparable-player average. Do not say the opponent “allows” saves, passes, tackles, or other player-event counts unless the source is genuinely a team-level allowed metric.

**Why:** “Vasco DA Gama allows an average of 3.3 saves to Goalkeeper” incorrectly assigns a goalkeeper event count to the team. The meaningful statement is that comparable goalkeepers averaged 3.3 saves in matching fixtures against Vasco.

**How to apply:** Use prop-specific stat names and observed-position cohort labels across cards, tactical narratives, summaries, and saved analysis. Include venue and sample size when available; reserve “allowed/conceded” for source data that measures team-level opponent output directly.

name: API-Football attacking grid columns
description: API-Football 4-2-3-1 row-four columns distinguish wide and central attacking midfielders.
---

For a 4-2-3-1 lineup, row 4 columns map left-to-right to LW, CAM, and RW. A row/formation match must not label every attacking-midfield column CAM; wide players such as Doku need LW/RW evidence.

**Why:** Treating all three columns as CAM produced a false central-position profile and misleading same-position analysis.

**How to apply:** Keep formation-specific column mappings explicit and add regression coverage whenever a provider grid interpretation changes.

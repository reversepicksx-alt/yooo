---
name: Trust-oriented evidence display
description: Product direction for making sports predictions auditable and honest about evidence quality.
---

The product should build trust by showing where evidence came from, how much evidence supports it, and when a provider did not return a verified value. Exact fixture-level context and visible unavailable states are preferable to inferred or silently substituted numbers.

**Why:** The user explicitly confirmed on August 9, 2026 that the recent provenance, context, and unavailable-data improvements made the system feel substantially more trustworthy.

**How to apply:** Keep evidence labels precise, preserve sample size and venue context, separate deterministic model output from optional AI explanation, and never fill a missing provider statistic with a derived estimate unless the UI clearly labels it as an estimate.
